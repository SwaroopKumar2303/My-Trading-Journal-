# My Trading Journal v3 — Monthly Calendar

Adds a monthly box/calendar view:
- Green day for net profit
- Red day for net loss
- Light shades for smaller moves
- Dark shades for larger moves
- Month navigation
- Monthly green/red day counts and net P&L
- Tap a day to see its trades

Replace the files in your GitHub Pages repository with these files. Refresh/reinstall the PWA if an older cached version remains.
